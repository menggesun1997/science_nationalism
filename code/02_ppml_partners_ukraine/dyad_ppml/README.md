# Ukraine dyadic PPML — 对 Russia 三部曲的适配

Russia 的三部曲（`../../02_ppml_partners_russia/dyad_ppml`）**部分适用**于
Ukraine。框架能套，但有两处 Russia 没有的改动。

```bash
python 1ukraine_screen_and_estimate.py   # 筛控制池 + 两断点趋势估计 + 验证
python 2plot_ukraine.py                   # 结果两格图（event study + 系数）
```

复用 Russia 侧建好的 `all_country_dyad_panel.csv`，不重新取数。

## 控制组是怎么选的，以及它为什么"看起来不平行"

**在哪看。** 逻辑在 `1ukraine_screen_and_estimate.py` 的 `screen()`；
产出在 `ukraine_control_screening.xlsx` 的两个 sheet：
`step1_eligibility`（谁被排除、理由、各集团体量）与 `ranking`（50 个
合格国按接近乌克兰的程度排序）。

**两步逻辑。**
1. *事前排除*（`EXCLUSION_REASON`）：六类国家在看 2022 后结果之前就
   剔除——直接受冲击/参战方（含 Russia 本身）、外流目的地、自身双边
   冲击、伙伴集团成员、其他制裁国、体量不足。
2. *按接近度排序*：剩 50 国，各算与乌克兰的分集团战前 log 斜率，取
   "最差那个集团的偏差"（`max_absdiff`）排序，选前 6。用最差集团而非
   平均，是为了不让某个集团被牺牲。

最接近乌克兰的前 10（`max_absdiff`，pp/年）：Argentina 3.94、
Mexico 4.41、Morocco 4.98、Chile 5.99、South Africa 6.44、Brazil 6.90、
Colombia 7.01、Venezuela 7.54、Thailand 8.08、Cuba 8.12。取前 6。

**为什么选出来的控制组不满足平行趋势——这不是 bug。** 调整前，乌克兰
对这 6 国的分集团战前趋势 θ_g 是 EU −2.2%、北美 −5.0%、亚洲 −5.1%、
中国 −3.9%、其余 −3.3%，**5/5 组全部显著违反平行趋势**。这无法靠换
控制组解决：合格池里全是新兴经济体，战前增速系统性快于乌克兰，且五个
集团份额之和恒为 1，任何控制组都不可能同时在五个集团上平行（已在
Russia 侧用扩池 + 合成权重验证过，救不了）。

方法因此不是"找一个平行的控制组"（不存在），而是把这个不平行**显式
建模掉**：θ_g 吸收既有漂移，剩下的 β 才是断点。调整后残余趋势为
EU −0.08%、北美 −0.10%、亚洲 −0.36%、中国 −0.14%、其余 −0.18%，
**0/5 失败，全部 p≥0.84**。整条逻辑是：承认不平行 → 量化（θ_g）→
调整 → 验证残余平行 → 读断点。

## 哪些照搬，哪些改

| 步骤 | 对 Ukraine | 处理 |
|---|---|---|
| Step 1 控制池 | 同一套 ex ante 排除 | **额外把 Russia 作为参战方排除**；按最接近 Ukraine 重新排序 |
| Step 2 趋势项 | 更刚需 | 战前 5/5 组 pre-trend 显著且比 Russia 更陡 |
| Step 3 断点 | **改为两个** | Ukraine 的 2014（Crimea+Donbas）是真实 level shift，非平滑过渡 |

## 为什么要两个断点

Russia 在 2014 前后是平滑过渡，一条线性趋势就够。Ukraine 不是：EU 组
事件研究里 2013 的 +40.7% 到 2016 的 +15.6% 有一次明显向下跳。只用线性
趋势会把这个真实的 2014 冲击误当成战前趋势，所以设定保留 2014 与 2022
两个嵌套断点，再叠加趋势：

```
P_ijt = exp( a_ij + mu_it
             + Σ_g θ_g · s_t     · UA_j · G_g(i)
             + Σ_g β14_g · D2014 · UA_j · G_g(i)
             + Σ_g β22_g · D2022 · UA_j · G_g(i) )
```

β22_g 是 2022 相对 2014–2021 的增量断裂。

## 结果（trend + two-event，top-6 控制池）

控制池：Argentina, Mexico, Morocco, Chile, South Africa, Brazil。

| 集团 | θ (%/yr) | β2014 | β2022 | β2022 p |
|---|---|---|---|---|
| EU | −2.20 | +1.3 | −3.0 | 0.36 |
| 北美 | −5.00 | −3.9 | +15.0 | <0.01 |
| 亚洲 | −5.08 | +0.8 | −17.2 | <0.01 |
| 中国 | −3.90 | +8.7 | +8.6 | 0.04 |
| 其余 | −3.31 | +13.7 | −10.0 | <0.01 |

验证：趋势 + 2014 step 调整后，残余 pre-trend **0/5 组失败**
（所有 p ≥ 0.84）。

## 两个 caveat（必须写进论文）

1. **北美 / 亚洲 / 中国三组体量薄**（Ukraine 年均仅数百篇），β 置信区间
   宽，in-space placebo 做不动，只能作探索性。主结果是 EU 与"其余"组。

2. **EU 组 β2022 近零（−3.0%，p=0.36）：乌欧合作份额战后保持稳定。**
   曾怀疑乌克兰学者外流到 EU、署名改变、机械抬高了 EU 合作量从而掩盖
   真实收缩。用 OpenAlex 双边学者迁移流
   （`migration_data/openalex_pipeline/results/openalex_bilateral_flows_1998_2025.csv`）
   检验后**否定了这个猜测**：28 个 EU 伙伴国的"迁移增量 vs 合作增量"
   相关系数仅 0.046；最大外流去向（德国迁移 +122、美国 +1096）的合作
   几乎没动（乌-德 +6、乌-美 −8）；量级也差 3 倍（EU 迁移增量
   1540/年 vs 正向合作增量 433/年）。迁移确实大增（到 EU +68%），但它
   与合作量变化没有可检测的机械关联，所以 dyad 口径的合作量可照常
   解读，**不需要 author-affiliation 重新归属**。

   曾进一步猜测 EU 近零是"组内方向不一"（邻国团结带升、西欧降相互
   抵消）。**逐个 EU 成员国单独估 β2022 否定了这个猜测**：28 国里显著
   上升 0 个、显著下降 1 个（斯洛伐克 −39%）、其余 27 国全不显著；
   "团结带邻国"与"大西欧"两组均值分别是 −6.4% 与 +1.6%，但两组都不
   显著，符号差异更像单国样本噪声而非真实分化（多数国 `ua_vol`
   在 100–800 篇/年，样本不算极小，故"全不显著"大概率是真无效应）。
   因此诚实结论是：**乌克兰与 EU 的合作份额战后既无整体显著变化，也无
   可检测的国别分化，保持稳定**——无需用异质性去解释一个本就干净的
   近零结果。

   口径提示：正文 L202 的 "Solidarity Belt" 叙述来自 partner-level
   内部控制组设定（`../2ppml_analysis.do`）。在本处的外部控制组 +
   趋势调整设定下，团结带的显著性消失。两种口径（内部 vs 外部控制组）
   结论不一致，撰文时需择一为准或明确说明差异。
