# 04_west_east_tilt

Russia and Ukraine, then two-way fixed-effects DiD, event study, and
in-time placebo tests.

- SI: H (control-group selection, parallel trends, placebos)

Scripts: `0cal_west_east_tile.py` → `1parallel_visual.py` →
`2conduct_did.py` → `3event_study_dynamic_did.py` → `4placebo_test.py`.
