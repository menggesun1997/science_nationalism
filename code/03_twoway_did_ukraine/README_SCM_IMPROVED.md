# 改进的SCM控制组选择 - 解决战前趋势问题

## 问题背景

之前的SCM控制组选择虽然通过了整体平行趋势检验（F检验p=0.7041），但在event study中，战前期的系数仍然显著，说明平行趋势假设在实际分析中未得到满足。

## 解决方案

创建了改进的SCM方法（`11scm_improved.py`），通过以下策略优化控制组选择：

1. **使用更近期的战前时期**：从2015-2021改为2019-2021（更接近处理时点）
2. **限制国家数量**：最多使用3个国家，避免过度拟合
3. **战前趋势检验**：直接检验整个战前期（2015-2021）的gap是否显著

## 最佳配置结果

经过多个配置的测试，最佳配置为：

- **战前拟合时期**：2019-2021（3年）
- **使用的控制组**：
  - ARMENIA (58.56%)
  - SOUTH AFRICA (41.44%)
- **RMSE**：0.039621
- **战前平均gap**：0.013470
- **战前gap的p值**：0.3198 ✅ **通过检验**

## 为什么这个配置更好？

1. **更少的国家**：只使用2个国家，避免了过度拟合
2. **更近期的拟合期**：使用2019-2021的数据，更接近处理时点（2022）
3. **战前趋势检验通过**：p=0.3198 > 0.05，说明整个战前期（2015-2021）的gap不显著

## 使用流程

### 1. 运行改进的SCM选择

```bash
cd .
python 11scm_improved.py
```

这将：
- 测试多个配置
- 选择最佳配置（战前gap的p值最大）
- 保存结果到 `scm_improved_results.xlsx`

### 2. 重新生成PPML-DiD数据

```bash
python 3generate_ppml_did_data.py
```

脚本会自动从 `scm_improved_results.xlsx` 读取控制组。

### 3. 运行Event Study

```stata
do 6event_study_analysis.do
```

现在应该看到战前期的系数不显著了。

## 注意事项

1. **控制组数量减少**：从5个国家减少到2个国家，可能会影响结果的稳健性。建议在论文中报告：
   - 主要结果：使用改进的SCM控制组（2个国家）
   - 稳健性检验：使用原始SCM控制组（5个国家）

2. **拟合期缩短**：使用2019-2021的3年数据拟合，而不是7年。这是为了确保更好的平行趋势，但可能会影响拟合质量。

3. **验证**：运行event study后，检查战前期的系数是否真的不显著了。如果仍然显著，可能需要进一步调整。
