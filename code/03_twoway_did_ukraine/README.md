# 03_twoway_did_*

External-control PPML DiD (SI G). The focal country is compared with a
data-driven control group of similar countries, selected by pre-trend
slope matching and RMSE minimization.

| Folder | SI section |
|---|---|
| `03_twoway_did_russia` | G.2 (South Africa, Brazil, Georgia) |
| `03_twoway_did_uk` | G.3 (Australia, Switzerland, Norway) |
| `03_twoway_did_eu` | G.4 (Norway, Australia, Switzerland, Canada) |
| `03_twoway_did_ukraine` | G; also documents SCM control selection |

This is a different identification strategy from `02_ppml_partners_*`
(internal controls). Both are kept because the paper reports them.
