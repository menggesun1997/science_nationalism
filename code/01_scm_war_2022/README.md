# 01_scm_war_2022

Nested synthetic control for the 2022 full-scale invasion.

The pre-treatment window is 2015–2021, so estimates are *marginal*
breaks relative to the already disrupted post-2014 trajectory, not
total effects relative to a pre-conflict path.
